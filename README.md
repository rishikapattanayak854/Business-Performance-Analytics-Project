# Business Performance Analytics

## Project Overview
Business Performance Analytics is a data analysis project focused on understanding business sales performance, customer behavior, and inventory management.

The project uses Python, SQL, and Tableau to clean, analyze, and visualize business data and generate meaningful insights.

## Project Objectives
- Analyze overall business sales performance.
- Understand customer purchasing behavior.
- Analyze inventory data.
- Identify sales trends and patterns.
- Create an interactive business dashboard.

## Tools & Technologies
- **Python:** Data cleaning and analysis.
- **Jupyter Notebook:** Python code execution.
- **Pandas:** Data manipulation.
- **SQL:** Database queries and business analysis.
- **Tableau:** Data visualization and dashboard creation.
- **CSV:** Dataset storage.

## Project Structure

- **Dataset:** Original and cleaned datasets.
- **Python:** Data cleaning notebook and dashboard image.
- **SQL:** Business analysis SQL queries.
- **Dashboard:** Tableau workbook.
- **Presentation:** Executive project presentation PDF.

## Dataset Description
The project includes three main datasets:

- Customers
- Sales
- Inventory

Cleaned versions of these datasets are also included.

## Project Workflow
1. Collect and explore business datasets.
2. Clean and prepare data using Python.
3. Perform business analysis using SQL.
4. Create visualizations using Tableau.
5. Present business insights through an executive presentation.

## Expected Outcomes
- Better understanding of sales performance.
- Insights into customer activity.
- Improved visibility into inventory data.
- Data-driven business decision support.
